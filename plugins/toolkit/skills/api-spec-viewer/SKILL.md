# API 스펙 카탈로그 만들기

**앱을 기동하지 않는다.** `/openapi.json` 을 받지 않고 소스 파일만 읽는다 — 의존성·DB·설정
없이 남의 레포에도 그대로 돌아간다. 대가로 런타임에 조립되는 라우트는 놓친다.

산출물은 **두 개**다. 하나로 합치지 않는다.

| 산출물 | 무엇 | 왜 따로인가 |
| :--- | :--- | :--- |
| `<이름>.json` | 스펙 스냅샷 | 사람이 보관·전달하고, `api-contract-diff` 의 입력이 된다 |
| `<이름>.html` | 카탈로그 화면 | 열람·공유용. 자체 포함 한 파일이라 그대로 보내면 열린다 |

## 1. 절차

1. **대상 소스 트리를 정한다.** 인자로 경로를 받았으면 그것, 아니면 현재 레포다.
2. **추출기를 고른다.** 프레임워크마다 실행 파일 하나다.

   | 소스에 있는 것 | 추출기 |
   | :--- | :--- |
   | `.java` · `@RestController` · `@GetMapping` | `extract-spring.py` |
   | `.py` · `APIRouter` · `@router.get(...)` | `extract-fastapi.py` |

   **둘 다 해당하면 트리마다 따로 돌린다.** 한 번에 섞지 않는다 — 스냅샷 하나는 프레임워크
   하나다. 둘 다 아니면 여기서 멈추고 사용자에게 알린다. **추출기를 억지로 맞춰 쓰지
   않는다** — 프레임워크를 늘리는 방법은 이 폴더에 파일 하나를 더하는 것이다.

3. **스냅샷을 뽑는다.** 출력은 stdout 이라 반드시 파일로 받는다.

   ```bash
   python3 extract-spring.py <소스 트리> > <이름>.json
   ```

   `rc=0` 이면 끝이다. `rc=3` 은 "엔드포인트를 하나도 못 찾았다" 이고 **성공이 아니다** —
   프레임워크를 잘못 골랐거나 그 트리에 API 가 없다. 빈 결과를 화면으로 만들지 않는다.

4. **HTML 을 만든다.** 입력은 앞 단계의 스냅샷 파일이다.

   ```bash
   python3 render.py <이름>.json > <이름>.html
   ```

   `render.py` 는 스냅샷의 스키마를 다시 단언한다. 키가 빠졌으면 **없는 키의 이름**을
   stderr 에 찍고 `rc=1` 로 끝난다. 엔드포인트가 0건이어도 `rc=1` 이다.

5. **둘을 같은 폴더에 나란히 둔다.** 경로를 지정받았으면 그곳에, 아니면 현재 작업
   디렉토리다. 이름은 `<레포이름>-api` 처럼 무엇의 스냅샷인지 알아볼 수 있게 짓는다.
6. **완료 보고에 두 경로를 모두 적는다.** JSON 을 빼먹지 않는다 — 다음에 `api-contract-diff`
   를 돌릴 때 그 파일이 입력이다.

### 두 시점을 비교하려면

같은 레포의 서로 다른 커밋에서 3 을 두 번 돌려 스냅샷 두 개를 만들고, `api-contract-diff`
스킬에 넘긴다. 이 스킬은 커밋을 받지 않는다 — 받는 것은 언제나 스냅샷 파일이다.

## 2. 스냅샷 JSON

형태는 같은 폴더의 `snapshot-schema.md` 가 정의한다. **두 추출기의 출력 형태는 같다** —
그 형태가 프레임워크 중립 diff 의 인터페이스다. 값은 소스에 적힌 문자열 그대로이고
타입을 정규화하지 않는다.

같은 입력에 두 번 돌린 출력은 바이트로 같다. 파일 경로·시각을 담지 않기 때문이다 —
스냅샷을 그대로 커밋해 두고 나중에 비교해도 흔들리지 않는다.

## 3. 화면

**playground 스킬의 `data-explorer` 템플릿이 출발점이다.** 자체 포함 HTML 한 파일,
다크 테마, 외부 의존 0 — 그 규약을 그대로 지킨다.

| 자리 | 무엇이 들어가나 |
| :--- | :--- |
| 왼쪽 컨트롤 | 경로·타입 검색 상자, HTTP 메서드 칩 필터, 걸러진 엔드포인트 목록 |
| 오른쪽 프리뷰 | 고른 엔드포인트의 요청·응답 스키마 트리. 모델 타입은 `<details>` 로 펼쳐지고 중첩 모델은 깊이 8 까지, 순환 참조는 표시하고 멈춘다 |
| **프롬프트 출력 자리** | **요청/응답 JSON 샘플과 복사 버튼**으로 바꿔 썼다 |

**playground 원본의 "프롬프트 출력 + 복사 버튼" 자리를 프롬프트가 아니라 JSON 샘플 복사로
쓴다** (사용자 결정 2026-08-29). 원본의 그 자리는 사용자가 조작한 결과를 프롬프트로 만들어
Claude 에 돌려주는 곳인데, API 카탈로그는 열람·공유가 목적이라 돌려줄 것이 없다. 대신
샘플 요청을 그대로 집어 `curl` 이나 테스트에 붙여 넣는 것이 이 화면에서 실제로 하는 일이다.
`api-contract-diff` 의 화면도 같은 자리를 같은 것으로 쓴다 — 두 화면의 조작이 어긋나지
않아야 한다.

샘플 값은 타입 이름에서 고른 자리표시자다(`Long`→`0`, `LocalDateTime`→ISO 문자열).
**실제 데이터가 아니다.**

## 4. 검사

```bash
bash check.sh
```

고정 커밋 샘플 두 레포를 받아 추출기 2종을 돌리고, 스키마 단언 · `render.py` 산출 ·
실패 경로(키 누락 · 엔드포인트 0건 · 없는 파일)를 함께 확인한다. 네트워크가 필요하다.
`check.sh <스냅샷.json>` 은 그 파일 하나에 스키마 단언만 한다.
