# Present a knowledge wiki

Choose the requested output before acting. For a live local managed reading website, read
[managed reader](../../references/reader.md) and launch its fixed audience/goal server.
For an agent answer from the same result, use `knowledge:query`.
For an explicitly requested managed local publication, read [relations](../../references/multi-repo.md)
and use the configured principal/audience; report every member outcome and partial failure.

For a static web preview read [wiki procedure](../../references/knowledge-wiki.md). Resolve the
reviewed canonical documents, manifest, reader purpose, source revision and evidence of review.
If content needs initial writing or updates, hand the inputs to `knowledge:bootstrap` or
`knowledge:update` and resume from their reviewed output. Rendering does not grant review status.
Use new external runtime/output directories as needed, then build, check, serve on loopback and
inspect the requested browser interactions. Keep inputs and installed package immutable.
A static preview cannot enforce current per-reader permissions: use only explicitly selected
shareable documents and never copy withheld managed bodies to bypass a denied read.

Finish with the exact content/build versions, actual browser observations and unverified scope.
Separate review, byte integrity, currentness and live implementation. Remote publication is
separately authorized; local preview is not deployment.
