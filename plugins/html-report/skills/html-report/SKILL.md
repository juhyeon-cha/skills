# 발표·공유용 HTML 자료 만들기

**템플릿은 `template.html` 하나다.** 치환 엔진도 빌드 단계도 없다 — 읽고, 지우고, 복제하고,
채운다. 산출물은 자체 포함 `.html` 한 파일이고, 그대로 열리거나 그대로 공유된다.

## 1. 절차

1. **내용을 정한다.** 인자로 파일 경로를 받았으면 그것을 읽고, 없으면 지금 대화에서 뽑는다.
2. `template.html` 을 읽는다. 통째로 읽는다 — 부품 창고가 아래쪽에 있다.
3. **섹션을 확정하고 채운다.** 마커 규칙은 §2. 부품이 필요하면 `PALETTE` 구역에서 복사한다.
4. `reports/<YYYY-MM-DD>-<슬러그>.html` 로 쓰고, §4 검사 두 줄을 돌린다.

## 2. 마커 — 이 셋이 전부다

```
<!-- SECTION: 이름 | 필수 -->  …  <!-- /SECTION: 이름 -->
```

| 표시     | 뜻                                                                |
| :------- | :---------------------------------------------------------------- |
| **필수** | 지우지 않는다. 표지·한눈에·결론 셋뿐이다.                         |
| **선택** | 채울 내용이 없으면 **여는 주석부터 닫는 주석까지 통째로 지운다.** |
| **반복** | 필요한 만큼 복제한다. 하나도 필요 없으면 지운다.                  |

**빈 절을 남기지 않는다. `N/A` 로도 채우지 않는다** — 채워진 빈칸은 검토한 것으로 읽힌다.

## 3. 산출물에서 지우는 것과 남기는 것

| 대상                            | 처리                                                           |
| :------------------------------ | :------------------------------------------------------------- |
| 모든 `SECTION` 주석             | **지운다.** 공유받은 사람이 볼 것이다.                         |
| `PALETTE:START` ~ `PALETTE:END` | **지운다.** 통째로.                                            |
| `{{중괄호}}`                    | **하나도 남기지 않는다.** 못 채우면 그 섹션을 지운다.          |
| 안 쓴 부품의 CSS                | **남긴다.** 셀렉터를 골라 지우다 쓴 부품 스타일을 같이 날린다. |

**외부 참조는 하나도 두지 않는다.** CDN, 웹폰트, 원격 이미지, `fetch` 전부 안 된다.
이미지는 `data:` URI 로 인라인한다. 나중에 아티팩트로 올려도 그대로 열린다.

## 4. 검증 — 실증 한 번과 grep 두 줄

만든 파일을 **실제로 열어본다.** 그리고:

```bash
grep -nE '\{\{|SECTION:|PALETTE:' reports/<파일>.html   # 아무것도 안 나와야 한다
grep -nE 'https?://' reports/<파일>.html                 # 본문 링크만 나와야 한다
```

**둘 다 형태만 보는 검사다. 걸린 줄을 읽고 판단한다.**

- 첫 번째가 `<pre>`/`<code>` **안**을 물었다면 그건 본문이다 — 마커 문법을 설명하는 자료는
  걸리는 게 정상이다. 코드 블록 **밖**에서 걸리면 지우지 않은 잔존이다.
- 두 번째는 본문 `<a href>` 도 같이 잡는다. 링크는 정상이고, `src`·`@import`·`url()` 에
  붙은 것이 걸리면 위반이다.

**출력을 `head` 나 개수로 줄여 읽지 않는다.** 없어야 할 것을 확인하는 검사라, 잘린 목록의
침묵은 증거가 아니다 (`.claude/rules/code-style.md` §2).

## 5. 부품 열 개

콜아웃(정보·주의·강조) · 표 · 통계 타일 · 코드 · 인용 · 이미지+캡션 · 세로 타임라인 ·
아코디언 · 탭 · 막대 차트+스파크라인. 전부 `PALETTE` 구역에 완성된 마크업으로 있다.

## 6. 남긴 천장

- **탭은 라디오+CSS다.** `role="tab"` 도 화살표 키 이동도 없고, 감춰진 패널은 `Ctrl+F` 로
  안 잡힌다. **검색돼야 하는 내용이면 탭 대신 `h3` 소제목을 쓴다.** 한 페이지에 탭 그룹이
  둘 이상이면 `name` 과 `id` 의 `t1` 을 바꾼다. 한 그룹 최대 4개 — 늘리려면 CSS 셀렉터를
  한 줄씩 추가해야 한다.
- **차트는 막대와 스파크라인뿐이다.** 꺾은선·산점도·다중 계열이 필요하면 `dataviz` 스킬을
  읽고 인라인 SVG 로 그린다. 여기에 두 번째 차트 규칙을 만들지 않는다.
- **다이어그램은 없다.** 필요하면 `artifact-diagramming` 을 읽고 인라인 SVG 로 그린다.
  ⚠️ **mermaid 는 쓸 수 없다** — `mermaid` 블록을 그려주는 것은 아티팩트 뷰어의 기능이지
  브라우저의 기능이 아니다. 로컬 `.html` 에서는 코드 덩어리로 보인다.
- **슬라이드 덱이 아니다.** 스크롤되는 문서 한 장이다.

## 7. 템플릿을 고칠 때

호출할 때 말로 하는 1회성 지시("이번엔 배경 빼고", "타일 대신 표로")는 템플릿을 건드리지
않는다. **같은 지시가 세 번 나오면 그때 `template.html` 에 넣는다** — 한 번 쓰인 취향이
영구히 박히는 것과, 매번 같은 말을 반복하는 것 사이의 선이다 (`.claude/rules/` R7).
