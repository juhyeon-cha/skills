# 설치 패키지에서 실제 작성·리뷰·적용

개발 저장소를 제공하지 않은 신규 Claude 세션이 복사한 toolkit 패키지를 읽고, 일회용 저장소의 재시도 변경을 문서에 반영했다. 프로젝트 CLI의 완료 상태와 최종 문서를 직접 확인했다. [실제 결정·리뷰·도구 기록](../../../../tests/knowledge/installed-observation/README.md)을 보존했다.

소스의 총 시도 횟수가 3회에서 4회로 바뀌자 작성자는 “최초 요청 외에 최대 세 번 더 시도한다(총 4회)”로 수정했다. 권한 오류와 최종 연결 오류에 관한 기존 문장은 유지했다. 실제 writing-for-humans와 backend 참조 문서를 읽었으며, 독립 리뷰어는 review-knowledge의 SKILL.md·rubric.md·response.md와 검토 자료를 읽고 네 기준을 통과로 판정했다. 이후 공개 review·resume으로 반영하고 기준 커밋을 승계했다.

첫 일반 역할 위임은 하네스가 역할을 식별하지 못해 도구 사용을 거부했다. 등록된 harness:reviewer로 다시 위임해 성공했다. 훅이나 사용자 설정은 변경하지 않았다. 스킬에는 호스트가 역할 식별을 요구할 때 등록된 독립 리뷰 기능을 사용하도록 명시했다.

리뷰어는 최종 문장에 오류가 없다고 판정했지만, 작성 이유의 “전체 소요 시간을 가늠”한다는 설명은 소스가 직접 뒷받침하지 않는다는 비차단 의견도 남겼다. 관측 응답을 수정하지 않고 보존했다. 한 사례의 통과는 임의 문서의 의미적 정확성을 보장하지 않는다.

이 실행은 단일 변경이다. 연속 A→B→C와 강제 종료 후 재개는 복사 패키지 자동 테스트로 별도 검증했다. 실제 실행 이후 추가한 검토 자료 변조·완료 후 문서 변조 방어도 자동 테스트의 검증 범위이며, 같은 모델 실행을 다시 수행한 것은 아니다. 마켓플레이스 릴리스 발행이나 모든 호스트에서의 자동 선택은 검증하지 않았다.
