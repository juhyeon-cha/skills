# 코드 기반 지식 자동화 로드맵

사용자가 문서 품질과 코드 변경의 영향을 매번 직접 확인하는 문제를 해결한다. 최종 목표는 코드·승인된 결정에서 지식을 구성하고, 변경을 검증해 반영하며, 그 지식을 다음 개발의 판단에 사용하는 흐름이다.

**현재 PR #328은 1단계의 초안이다.** 설치 패키지 실행과 반복 갱신 등 일부 기능은 검증됐지만, 체계적인 전체 흐름이나 1단계 전체 완료를 뜻하지 않는다. 이전 단기·중기·장기 구분을 아래 총 5단계로 대체한다. 일정·담당·제품 도입은 아직 확정하지 않았다.

## 단계와 현재 위치

| 단계 | 사용자에게 제공할 결과 | 현재 상태 | 세부 조건 |
|---|---|---|---|
| 1. 실행 기반 확립 | 기존 문서의 갱신을 설정부터 실패 복구까지 같은 계약으로 실행 | 초안 구현, 통합 완료 미판정 | [1단계](stages/01-foundation.md) |
| 2. 최초 지식 구성 | 문서와 근거 연결을 미리 작성하지 않아도 첫 지식 묶음을 구성 | 미착수 | [2단계](stages/02-bootstrap.md) |
| 3. 변경에 따른 지식 유지 | 추가·수정·삭제와 결정 변경을 영향 지식에 반영 | 미착수; 일부 실행 부품은 1단계 초안에 존재 | [3단계](stages/03-maintenance.md) |
| 4. 개발 흐름과 자동 연결 | 개발 이벤트·정기 검사로 실행하고 필요한 예외만 사용자에게 전달 | 미착수 | [4단계](stages/04-automation.md) |
| 5. 지식 활용과 고도화 | 여러 저장소의 검증된 지식을 검색·개발 판단에 활용하고 품질을 개선 | 미착수 | [5단계](stages/05-feedback.md) |

각 단계의 상세 조건과 판정 시나리오는 해당 문서가 소유한다. 다음 단계의 설계·실험은 병행할 수 있지만, 선행 조건이 미충족이면 후속 단계 완료를 선언하지 않는다. 개별 부품이 먼저 구현돼 있어도 단계 전체의 상태를 올리지 않는다.

## 공통 설계 원칙

- 보존한 원본 근거(`raw`), 현재 유효한 지식(`knowledge`), 독자별 설명을 구분하되 사실 원본은 하나로 유지한다. 문서에서 근거 버전과 위치로 돌아갈 수 있어야 한다.
- 코드는 구현된 동작의 근거다. 의도는 승인된 결정 기록에서 찾으며, 고정 커밋의 동작을 배포 환경의 동작으로 간주하지 않는다.
- CLI는 파일·버전·자료 계약·상태·반영 조건을 검사한다. 에이전트는 의미 해석·작성·독립 리뷰를 맡는다. `writing-for-humans`는 작성 책임만 가진다.
- 라이브러리는 검증된 표준 처리에 재사용한다. 스킬 수나 자체 CLI 규모를 목표로 삼지 않는다. [부품 조사](research/components-and-boundaries.md)는 후보 조사이며 도입 결정이 아니다.
- 일반적인 수정은 에이전트가 처리한다. 근거 충돌, 정책 선택, 승인 범위 변경은 근거와 영향과 함께 사용자에게 전달한다. 원격 반영·삭제·마이그레이션 승인 경계는 유지한다.
- 형식 검사와 의미 검증을 구분한다. 작성자와 독립된 리뷰, 문서만 읽는 풀이, 의도적 결함 검출을 필요한 시나리오에 적용한다. 원본 없이 성공을 주장하지 않는다.
- Promptfoo와 LLM 응답 평가 플랫폼은 전체 흐름 구현 후 5단계에서 필요성을 검토한다. 도입 자체는 완료 조건이 아니다.

## 완료를 판정하는 방법

각 조건 ID는 스토리의 수용 기준(AC: 결과가 충족해야 할 관찰 가능한 조건)으로 이어진다. 스토리 착수 시 적용 범위·고정 입력·기대 결과를 정하고 정상·실패 사례로 검증한다. 완료 보고에는 입력과 도구 버전, 실제 산출물, 독립 판정, 실패와 재개 기록, 사용자 개입 이유, 미검증 범위를 연결한다. 필수 조건의 실패나 미검증을 평균 점수로 상쇄하지 않는다.

단계 문서는 계획의 원본, `contracts/`는 현재 구현 계약, `experiments/`는 과거 관측이다. 태스크 실행 상태는 원장에서 관리한다. [PR #328의 K1–K5 검증](acceptance.md)은 1단계 초안의 증거로 보존하며 단계 전체의 완료 기준을 대체하지 않는다.
