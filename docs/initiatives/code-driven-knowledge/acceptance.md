# 이번 기능의 완료 조건

이번 기능은 플러그인 설치 사용자가 **기존 문서와 코드 근거를 연결하고 연속된 코드 변경을 반복 반영하는 것**까지 완료해야 한다. 이전의 개발용 CLI·단일 사례 통과는 부분 결과이며 아래 기준을 대체하지 않는다.

| ID | 완료 조건 | 확인 방법 |
|---|---|---|
| K1 | 개발 저장소 없이 배포 패키지만으로 설정·수집·작성·리뷰·적용을 수행한다 | toolkit 패키지만 복사한 새 디렉터리와 별도 소스 저장소에서 공개 CLI 사용 |
| K2 | A→B 완료 후 B→C를 처리하며 기준과 근거 연결을 자동 승계한다 | 연속 두 변경의 문서 내용과 기준 커밋·근거 연결 대조 |
| K3 | 프로젝트 위치와 실행 ID로 상태 확인·재개하며 동시 실행과 중복 적용을 통제한다 | 중단·새 프로세스·부분 반영·중복 요청·동시 쓰기 검사 |
| K4 | 각 스킬의 필수 파일이 스킬 안에 있고, 다른 스킬은 명시된 의존성으로 사용한다 | 설치 파일 검사, 스킬 로컬 참조 검사, 배포 경로를 바꾼 실행 |
| K5 | 별도 에이전트가 실제 스킬 파일을 읽고 지식 갱신·리뷰를 수행한다 | 신규 세션의 파일 읽기·도구 실행 기록과 실제 결과 보존 |

기존 문서의 새 주장 생성, 새 문서 생성, 여러 저장소, 원격 게시, Promptfoo와 LLM 평가 플랫폼은 이번 조건에 포함하지 않는다. 사용자 파일을 덮어쓸 수 있는 적용 경로의 회귀 검증은 유지한다. 배포 원본 구현·설치 표면 검증과 원격 릴리스 발행은 별도이며 릴리스는 명시적 요청을 따른다.

## 이번 변경의 판정

| 기준 | 결과와 근거 |
|---|---|
| K1 | 통과. toolkit만 복사한 경로에서 공개 CLI 실행 및 신규 에이전트 작성·리뷰·반영 |
| K2 | 통과. 별도 프로세스로 두 연속 변경을 처리하고 문서·기준·근거 연결 자동 승계 확인 |
| K3 | 통과. 파일 반영 직후 프로세스 강제 종료 후 재개, 활성 실행 충돌, SQLite 동시 쓰기, 중복 요청·과거 실행·변조 검사 |
| K4 | 통과. 두 스킬의 로컬 파일 참조 검사, 명시된 작성·리뷰 의존성, 패키지만 복사한 실행 |
| K5 | 통과. [신규 세션의 실제 파일 읽기·독립 리뷰 관측](experiments/installed-workflow.md). 일반 역할 위임 실패와 등록 역할 재시도 성공을 함께 기록 |

최종 회귀 검사는 40개(자료 10, 영향 6, 적용 11, 리뷰 연결 6, 프로젝트 7)가 통과했다. 두 스킬 형식 검사와 저장소 필수 게이트도 통과했다. 저장소 전체 테스트 묶음과 원격 릴리스는 실행하지 않았다. 별도 외부 구현 리뷰는 자동 승인 검토가 사설 코드 전송 사유로 거절하여 실행하지 않았으며, 로컬 코드 검토와 위 검사로 검증했다.
