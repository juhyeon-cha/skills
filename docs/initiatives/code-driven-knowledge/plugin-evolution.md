# knowledge 플러그인 고도화

문제는 지식 관리의 생성·변경·검토·조회·운영이 한 스킬 아래 모여 역할별 호출과 검증이 어렵다는 것이다.

## 1단계: 배포 경계 추출

knowledge 플러그인이 실행 코드·계약·검토·공통 참조를 소유한다. toolkit은 범용 작성 스킬을 제공한다.
기존 두 진입점은 knowledge namespace로 이동하며 DB v1과 실행 상태 형식을 유지한다.
이 단계는 여섯 작업별 스킬 분리나 검색 품질 개선을 완료했다는 뜻이 아니다.
이전 호출자의 전환은 [배포 안내](../../../plugins/knowledge/references/transition.md)를 따른다.
설치본 변경·릴리스·운영 게시·DB migration은 포함하지 않는다.

## 후속 순서

| 순서 | 결과 | 검증할 질문 |
|---|---|---|
| 작업별 진입점 | bootstrap/update/review/query/wiki/operate가 각 작업을 직접 안내 | 전체 갱신 절차를 읽지 않고도 필수 근거·검토·인계를 빠짐없이 수행하는가? |
| 조회·위키 일관성 | 같은 근거에서 에이전트 답변과 사람용 화면을 생성 | 부분 완료·목표 철회·권한 제한·오래된 색인이 양쪽에 동일하게 표시되는가? |
| 운영·품질 개선 | 실패 복구와 실제 평가를 반복 가능하게 제공 | 잘못된 영향 예측과 갱신 실패가 숨지 않고, 중복 실행 없이 복구되는가? |

세부 태스크와 수용 조건은 각 단계 착수 때 관측을 바탕으로 고정한다.

작업별 진입점 분리는 skills#411에서 완료했다. 여섯 스킬이 각 입력·의존성·완료 경계를 소유하고 공통 참조와 실행 상태를 공유한다.
`multi_repo.py`는 자동화 실행기 대신 공유 함수 모듈을 가져온다. 공개 CLI와 DB 형식은 유지한다.
고정 8개 요청에서 기존 방식과 후보 모두 필수 경계를 통과했다. 이는 직접 호출 계약의 관측이며 검색 품질이나 비용 개선의 입증은 아니다.
원본 응답과 판정은 [실험 기록](../../../tests/knowledge/task-skills-observation/README.md)에 있다.
조회·위키 일관성은 skills#417에서 다룬다. 공통 `read` 결과를 에이전트와 로컬 웹 화면이 사용하며,
페이지 요청마다 권한·현재 근거를 다시 검사한다. 정적 위키는 별도 스냅샷 경로로 유지한다.
[관리형 읽기 절차](../../../plugins/knowledge/references/reader.md)에 실행 방법과 한계가 있다.
실제 두 저장소의 작성·변경·독립 검토·부분 완료·정상 완료·실패 복구와 브라우저 관측을 연결한다.
skills#423은 관리형 읽기에 첫 차단 단계·진단·다음 조치를 추가한다. 현재 검사 실패와 오래된 검사,
문서 근거 불일치와 검토 대기를 구분하며, 기존 조회·게시 판정과 저장 형식은 유지한다.
권한 밖 진단은 숨기고 알 수 없는 오류는 근거 확인 불가로 표시한다.
[진단 관측](../../../tests/knowledge/diagnostics-observation/README.md)은 고정 입력, 기존 방식 비교,
실제 독자 답변과 브라우저 확인을 합성 검토 영수증과 구분한다.
운영 스케줄러·중앙 서비스·검색 품질 확대는 후속 범위다.
공통 자료의 단일 소유를 유지하고, 스킬마다 별도 상태 DB를 만들지 않는다. 공통 로직은 작업별 분리 단계에서 자동화 실행기 의존성을 제거했다.

## 실험 원칙

기존 방식과 새 방식에 같은 코드·목표·독자 질문을 제공하고 기대 답과 근거를 먼저 고정한다.
정답·출처 일치, 부분 완료 오표시, 권한 밖 정보 노출, 실패 복구를 판정한다.
의미 판단은 실제 독립 모델로 검증하고 시험 응답과 구분한다. 비용·호출·지연·개입은 관측값만 기록하며 미제공 값은 미측정으로 남긴다.
로컬 SQLite와 파일 방식에서 관측한 병목 없이 중앙 DB·검색 엔진·새 평가 플랫폼을 전제하지 않는다.

배포 경계 추출 원장은 skills#405, 작업별 진입점 원장은 skills#411이다. 과거 실험·고정 fixture의 경로와 해시는 당시 패키지의 기록으로 보존하며 현재 실행 명령으로 읽지 않는다.
