# 2단계: 최초 지식 구성

문서와 주장별 근거 연결을 사람이 미리 작성하지 않아도, 저장소와 문서 목적에서 첫 지식 묶음을 구성한다.

[전체 로드맵](../roadmap.md) · 단계 상태: 미착수

## 진입 조건

1단계 실행·검증·복구 계약이 성립하고, 단일 저장소의 포함·제외 범위와 독자를 지정할 수 있어야 한다.

## 세부 조건

| ID | 항목 | 확인할 결과 |
|---|---|---|
| S2-01 | 수집 범위 | 코드·설정·기존 문서·승인된 결정 기록의 출처와 버전을 고정한다. 누락·접근 불가·제외 항목을 보고하고 의도와 구현의 근거를 구분한다. |
| S2-02 | 지식 구성 | 용어·정책·조건·예외·관계를 추출하고 각 주장에 근거를 연결한다. 근거 없는 해석은 확정 지식으로 승격하지 않는다. |
| S2-03 | 문서 생성 | 공통 도메인 문서와 독자별 안내를 생성한다. 공통 정책의 원본을 하나로 두고 직무별 차이는 참조해 설명한다. |
| S2-04 | 범위와 누락 | 선택한 범위의 필수 항목을 수집·문서화·미확정·제외 상태로 대조한다. 문서가 생성됐다는 이유로 수집 범위 전체를 다뤘다고 판단하지 않는다. |
| S2-05 | 독립 검증 | 원본에서 기대 결과를 먼저 고정하고 독립 판정한다. 문서만 읽는 풀이자는 코드·정답을 받지 않으며 핵심 시나리오의 행동과 근거를 제시한다. |
| S2-06 | 기준 확정 | 검증된 최초 지식·문서·근거 연결을 갱신 가능한 기준으로 저장한다. 같은 입력의 재시도는 중복 문서나 서로 다른 활성 기준을 만들지 않는다. |

## 필수 판정 시나리오

지식 문서가 없는 사례와 일부 문서만 있는 사례에서 최초 구성을 수행한다. 결정 기록 누락, 서로 다른 정책 설명, 필수 예외 누락을 넣어 확정 지식과 미확정 항목을 구분하는지 확인한다.

## 완료 조건과 증거

모든 S2 조건을 통과하고 결과를 1단계 갱신 흐름의 입력으로 사용할 수 있어야 한다. 사람이 주장별 연결을 대신 작성했다면 최초 구성 자동화는 완료가 아니다. 검증 자료는 [공통 판정 규칙](../roadmap.md#완료를-판정하는-방법)을 따른다. 이 조건들은 구현 목표이며 현재 통과 주장으로 읽지 않는다.

## 현재 증거와 남은 일

미착수. 현재 CLI의 초기 근거 연결 입력과 기존 문서 갱신은 재사용 후보이며, 최초 지식 구성 자체의 구현 증거는 아니다.

## 제외 범위

변경 이력 전체의 자동 처리, 이벤트 실행, 여러 저장소는 후속 단계다.
