# 3단계: 변경에 따른 지식 유지

최초 구성한 지식을 코드와 승인된 결정의 변화에 맞춰 추가·수정·통합·폐기하고 변경 이유를 추적한다.

[전체 로드맵](../roadmap.md) · 단계 상태: 미착수

## 진입 조건

2단계에서 검증한 최초 지식과 근거 연결을 사용하며, 처리할 변경 전후 버전과 적용 순서를 고정한다.

## 세부 조건

| ID | 항목 | 확인할 결과 |
|---|---|---|
| S3-01 | 변경 분류 | 추가·수정·삭제·이동·이름 변경 후보와 결정 변경을 구분한다. 파일 이동을 정책 동일성으로 단정하지 않는다. |
| S3-02 | 영향 분석 | 직접 연결된 주장뿐 아니라 공통 정책을 참조하는 문서와 새 근거의 미연결 항목을 검토한다. 영향 없음 판정도 근거와 함께 남긴다. |
| S3-03 | 지식 수명주기 | 기존 주장 수정 외에 새 주장·문서 생성, 중복 통합, 더 이상 유효하지 않은 지식의 폐기·보존 규칙을 정의하고 검증한다. |
| S3-04 | 충돌 처리 | 코드·결정·문서 간 충돌을 탐지한다. 근거로 해소할 수 있는 수정은 내부 처리하고 정책 선택만 사용자에게 요청한다. |
| S3-05 | 순서와 재처리 | 연속·중복·역순 변경과 실패 후 재개에 대해 기준 일관성을 유지한다. 승인된 결과와 현재 문서가 달라지면 적용을 멈춘다. |
| S3-06 | 색인과 추적 | 문서·근거 검색 색인·현재 지식이 같은 근거 버전을 가리킨다. 현재 주장에서 원본과 변경 이유로, 변경에서 영향 문서로 추적할 수 있다. |

## 필수 판정 시나리오

2단계 산출물에 정상 수정, 새 기능, 삭제·이름 변경, 결정 변경, 무관한 변경을 연속 적용한다. 역순·중복 요청과 문서 충돌을 포함하고 영향받지 않아야 할 문서의 보존도 확인한다.

## 완료 조건과 증거

모든 S3 조건에서 예상 영향과 실제 수정·보존 결과가 일치하고, 실패 뒤에도 유효 기준과 이력을 복구할 수 있어야 한다. 검증 자료는 [공통 판정 규칙](../roadmap.md#완료를-판정하는-방법)을 따른다. 이 조건들은 구현 목표이며 현재 통과 주장으로 읽지 않는다.

## 현재 증거와 남은 일

미착수. PR #328의 파일 영향 후보·기존 주장 수정·기준 승계·재개는 선행 부품이다. 새 지식 생성·폐기와 의미 관계까지 포함한 유지 흐름은 미완성이다.

## 제외 범위

PR 이벤트 구독·스케줄러·원격 게시·저장소 간 영향은 포함하지 않는다.
