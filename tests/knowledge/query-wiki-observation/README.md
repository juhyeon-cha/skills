# 조회·웹 위키 일관성 관측

원장 skills#417. 기준 main `2fe1918`. M0는 먼저 고정한 6상태 입력과 정답으로 기존 query/wiki에서 공통 읽기를 구성할 수 있는지 판정했다. [M0 결과](m0-results.json)에는 시험용 영수증만 사용했고 [별도 실제 모델 판정](m0-verdict.json)은 그 경계를 명시한다.

[실제 파일럿](live-pilot/README.md)은 두 로컬 Git 저장소에서 여섯 스킬 절차를 실행했다. 실제 reader·reviewer 7회, 초기 문서/의도 결함/변경 packet/부분·통합 검증, 공개CLI apply 및 응답 유실 가정 재개가 포함된다. 모델 영수증은 실제 host agent 응답이며 인증된 provider 감사 기록은 아니다. 명령 지연과 모델 대기 시간은 구분한다.

[브라우저 계획](browser-plan.json)은 후속 상태 변경 전에 질문과 기준을 고정했다. [실제 CUA 관측](browser/observations.md)과 상태별 공통 read JSON은 정상·부분 완료·권한 철회·문서 drift/갱신 거절·체크 실패·목표 철회를 보존한다. 정상 결과 ID가 CLI와 실제 evidence 페이지에서 일치했다. [독립 독자 답변](browser/reader-answers.json)은 여섯 응답 각각에 대해 고정한 다섯 질문에 필드·값·결과 ID를 인용한다. 원본 도구 출력은 작업 대화에 있고, 브라우저 export는 미지원이다. 직접 거절 페이지는 IAB가 열지 않았으므로 서버404 근거는 실제HTTP 검사와 구분한다.

현재 `read`는 문서 drift와 체크 실패를 모두 `pending_or_stale`로 보여준다. 결과 ID가 같아도 실패 원인이 같다는 뜻은 아니다. 상세 진단과 복구 원인은 기존 실행 trace에 있다. 본문은 검토된 원문 텍스트로 표시하며 별도 Markdown 변환이나 출처 재작성은 하지 않는다.

## 보존과 재실행

이 디렉터리는 당시 결과의 원본 바이트다. 절대 경로·소스 revision·요청 ID는 관측 좌표로 보존했고 현재 설치 경로로 해석하지 않는다. `live-pilot/artifact-manifest.json`은 브라우저 실패 주입 **전**의 파일럿 스냅샷 목록으로, 후속 host/state 변화를 포함하지 않는다. `files.sha256.json`은 이 전달에서 보존하는 최종 파일들의 해시다.

실제 Git/SQLite 상태는 임시 실험 경로에 유지하며 배포 패키지나 이 관측 폴더에 복제하지 않는다. 새 실행에는 별도 입력과 독립 모델 응답이 필요하다. 저장된 review 응답을 새 packet의 판정으로 사용하지 않는다. 기존 관계 ID 불일치 실패와 철회 intake 분류 실패는 성공으로 덮지 않고 별도 원본으로 남겼다.

제품 회귀는 `tests/knowledge/reader-check.sh`의 실제 HTTP·CLI와 기존 knowledge wrapper를 사용한다. 그 모델 응답은 시험용이며 위 실제 모델 호출과 합산하지 않는다. 운영 계정·설치·배포·다중 사용자 인증·동시 외부 편집의 원자성·실제 네트워크 응답 유실은 검증하지 않았다. 토큰·금액은 미제공이며 검색 정확도/성능 개선을 주장하지 않는다.
