# 질문 중심 설명과 역할 간 사례 연결

`reader-composition/documents`를 바탕으로 같은 합성 주문 취소 자료를 다시 구성한
작성 예제다. 이전 관찰 문서·응답·해시는 변경하지 않았다.

- 질문형 제목의 첫 문단에서 조건과 한계를 포함한 답을 제시한다.
- 화면·서버·협의·정책/제품 질문으로 바로 이동하는 읽기 경로를 제공한다.
- 응답 유실이라는 같은 사례에서 조회 계약, 화면 복구, 수용 조건, 제품 범위의
  의존성을 연결한다. 추가 협의는 제안으로 표시하며 원문의 확정 정책과 구분한다.
- 기존 흐름도·카드와 코드·정책의 조건, 미정 사항, 근거를 유지한다.

변경 작성자가 원문 코드·의사결정 자료와 기존 12개 내용 기준을 대조했다.
새 독자 실험이나 독립 검토는 수행하지 않았으므로 앞선 독자 평가 결과를
이번 예제의 결과로 재사용하지 않는다. manifest의 독립 검토 상태도 대기다.

정적 위키 빌드와 무결성 검사를 통과했고 본문 링크 21개가 유효하다.
브라우저에서 질문별 읽기 경로와 협의 절의 실제 표시 및 제목 앵커 도착을 확인했다.
저장소 gate도 통과했다. 이번 변경은 문서만 수정했으며 렌더러 회귀 suite는
재실행하지 않았다. 실제 이해 속도 향상, 설치본 반영, 운영 서비스 동작은 미검증이다.

재현은 `reader-composition/README.md`의 명령에서 입력 디렉토리를
`tests/knowledge/reader-questions/documents`로 바꾸고 새 출력 경로를 사용한다.
