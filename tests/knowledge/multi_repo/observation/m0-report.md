# 5단계 M0 관측

두 저장소의 부분 구현을 기존 단일 저장소 계약만으로 전체 완료와 구분해 조회할 수 있는지 확인했다. 원본 S5-01~06은 `original-stage5.md`, 전체 후속 시나리오·질문·정답 근거·품질/비용 기준은 실험 전 작성한 `frozen-plan.json`과 `freeze-hashes.json`으로 보존했다. M0는 5단계 전체 완료가 아니다.

## 실제 관측

`m0-observation.json`은 Python 3.14.7, jsonschema 4.26.0, 격리된 로컬 Git 두 저장소에 대한 원문이다. svc-producer/svc-consumer는 논리 ID, `/private/tmp/...`는 경로, `.invalid` URL은 연결하지 않은 예시다. 생산자만 amount→total로 변경했을 때 단일 저장소 영향 분석은 생산자 문서 후보 1개를 반환했다. 실제 두 소스의 연결 실행은 소비자의 `KeyError: amount`로 실패했다. 생산자 내부 성공으로 전체 계약 완료를 판정할 수 없다.

`status --deep`에 대응하는 서비스 호출은 소스 HEAD 변경 후에도 기록된 이전 baseline을 반환했다. 이는 현재 계약대로 저장된 상태와 내보낸 자료의 무결성을 보여주며 실시간 소스 최신성을 보증하지 않는다. 없는 저장소 경로의 capture는 실패했다. 이 실행은 운영 권한 거부를 재현한 것이 아니며 현재 제품에 다중 저장소 접근 제어·부분 공개 기능은 없다.

첫 관측 스크립트는 status baseline의 문자열을 객체로 잘못 읽어 마지막 assertion에서 실패했다. 이미 만든 두 저장소·프로젝트를 그대로 보존하고 실제 status를 읽은 뒤 별도 `replay-2` 경로에서 다시 실행했다. 경로 변경은 논리 ID·입력·판정 기준을 바꾸지 않았다. 두 번째 실행의 원문만 완료 관측으로 보존한다. `m0-replay.py`는 당시 실행 코드이며 고정된 절대 경로를 가진 역사 자료다.

실제 독립 모델 입력은 `model-prompt.md`, 분리된 사전 기대는 `model-expected.json`이다. 부모가 보존하는 실제 dispatch identity·시간·원문을 이 자료와 함께 판정해야 한다. 모델은 양쪽 영향, 미완료 및 잘못된 위키 문장을 찾아냈다. 권한 철회가 목표 범위를 줄이지 않는다는 판단도 했으나 공개 출력의 무권한 근거 제거까지 명시하지 않았다. 따라서 권한 공개 품질 전체 통과 근거가 아니다. 시험용 응답을 실제 모델 호출로 계산하지 않았다. 모델 사용량·금액은 제공되지 않아 미측정이다.

## 해소한 전제와 필요한 최소 계약

기존 capture/bind/impact/project를 저장소별로 재사용할 수 있다. 다만 impact는 선언된 단일 저장소 근거만 따르므로 호출 저장소 관계는 별도 공유 목표에 연결해야 한다. 최소 추가 경계는 (1) 논리 저장소 ID와 경로·URL을 분리한 등록, (2) 목표 ID/버전과 전체 필수 저장소 집합, (3) 저장소별 현재 커밋·목표 버전·검증 근거·관측 시점·실패/접근 상태, (4) 권한과 현재 소스를 다시 확인하는 재생성 가능 검색/위키 조회, (5) 영향 예측과 실제 변경·검증의 비교다. 하나의 파일 기반 집계부터 시작할 수 있으며 중앙 DB나 검색 엔진을 요구하는 병목은 이 두 저장소 관측에서 나오지 않았다.

현재 조회를 위한 근거가 접근 불가하면 전체 완료를 만들 수 없다. 원본 권한 철회 시 관리되는 조회/렌더 경계에서 노출을 막아야 한다. 이미 복사된 정적 페이지의 바이트 회수는 보증할 수 없다. 원본·비공개 역사와 공개 산출물의 범위를 구분해야 한다.

## 후속 검증

코드 선행·문서 선행의 전체 흐름, 목표 철회, 실제 부분 권한 공개, 한 저장소 갱신/게시 실패, 오래된 색인, 예측 오류의 지식 환류는 후속 구현과 독립 판정이 필요하다. 수동 저장소별 조회와 동일 질문의 관리 조회를 비교하고 실제 지연·개입·모델 호출 수를 기록한다. Promptfoo·검색 엔진·중앙 DB는 전체 흐름에서 남는 병목을 확인한 뒤 판단한다. M0에서 관측하지 않은 운영 서비스·운영 저장소·위키 계정·비용 우위·일반 의미 정확성은 주장하지 않는다.
